## 🧩 About

**Abiotic Factor catalog Menu** is a curated list of Abiotic Factor open-source tools:

- **Overlays** — on-screen helpers, layout notes, container viewer, quick-slot organizer
- **Quality-of-Life Helpers** — item catalog, crafting notes, overlay notes
- **Research Notes** — base layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Inventory Manager — quick-sort and filter items
- Crafting Assistant — show missing recipe ingredients
- Resource Tracker — mark nearby resource nodes
- Time Control — adjust day/night speed for study (0.5x to 4x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse weapons, tools, armor, and trinkets
- Custom Loadout Notes — organize gear sets
- Highlight Interactables — improved object visibility

### 🏋️ Base Layout
- Base Planner Notes — segment study of base designs
- Power Grid Viewer — trace generator connections
- Storage Overlay — label containers with contents
